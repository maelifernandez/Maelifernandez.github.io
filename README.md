# Portfolio — Maëli Fernandez

A fast, bilingual (EN/FR) one-page portfolio site + three project pages.
Pure HTML / CSS / JavaScript — **no build step, no installation.** You can open
it, edit it, and publish it just by moving files around.

## ✏️ How to change the text

**All the wording is in one file: `js/i18n.js`.**

Open it in any text editor. You'll see two blocks: `en:` (English) and `fr:`
(French). Each line looks like this:

```js
"hero.sub": "Event project coordinator — venues, suppliers, budgets...",
```

Change **only the text between the quotes** on the right. Keep the key on the
left (`"hero.sub"`) exactly as it is. Edit the same line in both the `en:` and
`fr:` blocks so both languages stay in sync. Save, refresh the page. Done.

> A few keys end in `.html` (e.g. `hero.title.html`). Those may contain little
> tags like `<em>…</em>` (that's the italic + violet underline). Just keep the
> tags balanced.

## 🖼️ How to add your photos

Put image files in the `assets/img/` folder, then:

**Portrait (About section):** open `index.html`, find the block that says
`<!-- Replace the placeholder below... -->`, and swap the placeholder for:

```html
<img src="assets/img/portrait.jpg" alt="Maëli Fernandez">
```

**Project visuals:** in a file like `projects/pour-faire-court.html`, find a
`<div class="shot">…</div>` and replace its contents with:

```html
<div class="shot"><img src="../assets/img/festival-1.jpg" alt="Festival evening"></div>
```

(Note the `../` in front of the path on project pages — they're one folder deep.)

When a section's visuals are all real photos, you can delete the small
`<span class="pending">Pending</span>` badge next to the "Visuals" heading.

## 🚀 Publish it online (free)

### Option A — Netlify (easiest, drag-and-drop)

1. Go to **https://app.netlify.com/drop**
2. Drag the **whole `portfolio` folder** onto the page.
3. Netlify gives you a live link in seconds (e.g. `maeli.netlify.app`).
4. To rename it: **Site settings → Change site name.**

To update later: drag the folder again onto the same site's "Deploys" area.

### Option B — GitHub Pages

1. Create a free account at **github.com**.
2. Create a new repository (e.g. `portfolio`), set it to **Public**.
3. Upload all the files from this folder (drag them into the repo's web page).
4. Go to **Settings → Pages**, set **Source: Deploy from a branch**, branch
   `main`, folder `/ (root)`, and **Save**.
5. After a minute your site is live at
   `https://YOUR-USERNAME.github.io/portfolio/`.

*(The empty `.nojekyll` file in this folder tells GitHub to serve the site
as-is — leave it there.)*

### Add your own domain later

Both services support custom domains for free (you only pay for the domain name):

- **Netlify:** Site settings → Domain management → Add a domain.
- **GitHub Pages:** Settings → Pages → Custom domain.

Each will show you the exact DNS records to enter at your domain registrar.

## 🎨 Design notes (for reference)

- **Colours** are defined once at the top of `css/style.css` (the `:root` block).
  Change a value there and it updates everywhere.
- **Fonts:** Fraunces (serif titles) + Inter (body), loaded from Google Fonts.
- The **constellations** are generated by `js/main.js` — decorative, no text.
- Everything respects "reduce motion" accessibility settings and works with a
  keyboard.
