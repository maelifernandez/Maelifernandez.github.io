Léon Event — corporate event agency

Jul – Dec 2026 Annecy, France Internship · Corporate events

Context

Léon Event is a corporate event agency in Annecy. As event project assistant, I supported the project manager across the full cycle — from client brief to signed proposal — on seminars, corporate parties and incentives.

Confidentiality: client names are never shown. Figures and examples will be added once verified for public sharing — described only by type and range.

My role

I worked alongside the project manager, turning client briefs into structured, comparable, decision-ready proposals.

What I did

  • Took client briefs and translated them into sourcing requirements.
  • Sourced venues, hotels, activities and suppliers to match each brief.
  • Built cost / capacity / logistics comparisons to guide the choice.
  • Assembled proposal decks and integrated client feedback through to signature.
